FRIOTECH · Gestión de activos

Base de datos publicada · v1.0

Proyecto personal de gestión de activos de refrigeración comercial con una base de datos demostrativa de 600 equipos distribuidos en 200 locales ficticios.

Incluye inventario, 2.100 órdenes de trabajo, técnicos, mantenimiento preventivo, repuestos, movimientos e indicadores operativos.

Tecnologías: Microsoft Excel · GitHub · Power BI (próxima etapa). Datos 100 % sintéticos.
